PARA PUBLICAR EN GITHUB PAGES

1. Descarga y descomprime este ZIP.
2. Sube index.html, styles.css, app.js y ramo_y_dedicatoria.jpg a la raíz de tu repositorio.
3. En GitHub, entra en Settings > Pages.
4. En Build and deployment, selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root), y pulsa Save.
6. Cuando GitHub Pages termine de publicar, comparte el enlace de tu web.

Al abrir la página solo se verá el botón «Pulsa aquí». Al tocarlo aparecerá el ramo y la dedicatoria.
